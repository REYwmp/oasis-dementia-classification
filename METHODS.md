# Data, labels and evaluation

## Which table survived?

The poster names longitudinal OASIS T1-weighted scans and lists MR Delay, CDR, MMSE, eTIV, nWBV and ASF. The recovered OASIS-2 table matches that description, with 373 visits from 150 people. The original source URL and working copy are unknown. The renewal uses a version-pinned copy of the tabular data. No MRI image files are needed. [Washington University dataset](https://sites.wustl.edu/oasisbrains/home/oasis-2/) · [Study publication](https://doi.org/10.1162/jocn.2009.21407) · [Kaggle distribution](https://www.kaggle.com/datasets/jboysen/mri-and-alzheimers) · [Exact CSV used here](https://github.com/NizarIslah/dementia-prediction/blob/de76175f53465fa0167dceb8cf57aabf717005c0/oasis_longitudinal.csv)

## Reading the original poster

The poster reports a 70/30 split, discusses z-score normalization, stratified cross-validation, Boruta and PCA, and shows nine models. Four features have Boruta rank 1 in the displayed table: Clinical Dementia Rating (CDR), Mini-Mental State Examination (MMSE), estimated total intracranial volume (eTIV) and normalized whole-brain volume (nWBV). The surviving material does not specify the exact final feature set, conversion rule, row assignments, feature-selection fit, tuned model settings or F1 averaging rule. The model comparison uses the four displayed rank-one features as a fixed historical clue. A companion script separately refits PCA and Boruta and allows their outputs to differ from the poster. [Poster reconstruction](poster_analysis.py)

### Rebuilding the feature analysis

Use the eight variables named in the original ranking table. Encode M/F as 1/0 for M/F, fit median imputation and z-score standardization on the 261 training visits, and use those rows for Pearson correlations, PCA and Boruta. PCA reaches 95% cumulative explained variance at six components. BorutaPy 0.4.3 uses a random forest of maximum depth five, automatic tree count, up to 100 iterations and seed 42. It confirms the four original rank-one variables plus years of education (EDUC) and atlas scaling factor (ASF). Feature importance here describes association with the reconstructed longitudinal group label. Rankings may change with the sample or fitting choices. [Ranks side by side](results/poster-reconstruction/boruta.csv) · [PCA curve data](results/poster-reconstruction/pca.csv)

The companion script fits all nine poster model families on the fixed four inputs and exports training and test confusion counts, accuracy, balanced accuracy and two definitions of F1. Retaining the fixed inputs allows direct comparison with the archive's visit-level reconstruction. ## How the new comparisons work

### Follow-up experiments for the renewal

**Split by visit or by person.** Use all 373 visits and the reconstructed longitudinal group label (Demented or Converted = 1). Fit the same XGBoost pipeline with MMSE, eTIV and nWBV. Assign folds using shuffled five-fold StratifiedKFold for visits and StratifiedGroupKFold with Subject ID for participants, both seeded at 42. Each visit is tested exactly once per protocol. Accuracy weights visits equally, so participants with more visits contribute more to the score. The fold audit counts held-out visits whose participant also appears in that fold's training data. The observed accuracy difference describes these two partitions in this cohort. The grouped folds have different training samples and varying class proportions, so the comparison cannot attribute the entire difference to overlap. [Fold audit](results/split-folds.csv) · [Pooled metrics](results/split-comparison.csv)

**Pair baseline predictions by person.** Use the same 150 baseline records, binary CDR outcome and folds as the participant-level reanalysis below. For each person, compare the held-out XGBoost prediction using MMSE alone with the prediction after adding eTIV and nWBV. The eight cells in the output count every combination of recorded outcome, first prediction and second prediction. Summing over either prediction recovers the other model's confusion matrix. [Paired counts](results/paired-baseline-errors.csv)

### Poster reconstruction and baseline evaluation

**Visit-level reconstruction.** The table contains 190 Nondemented, 146 Demented and 37 Converted visits. Combining Demented and Converted as class 1 yields the poster's 50.9%/49.1% class proportions. This is a plausible reconstruction of the historical coding. It gives some pre-conversion visits a positive label. After sorting by subject and visit, a stratified 70/30 split with seed 42 gives 261 training and 112 test visits. Seventy people appear on both sides. Two runs use exactly the same rows, one with all four rank-one features and one excluding CDR. These runs illustrate how a label-related input affects the score on this particular split.

**Participant-level reanalysis.** Keep each person's first visit and classify its recorded global CDR as zero or above zero. This uses the visit rating even when a participant's longitudinal group label differs. There are 85 zero and 65 positive ratings. Withhold CDR, group, identifiers and subsequent observations from predictors. Use the same five shuffled stratified folds (seed 42) for all models and feature sets. Each of the 150 people contributes one out-of-fold prediction. Compare two MRI summaries plus MMSE, MRI summaries alone, and MMSE alone.

**Fitting and metrics.** Fit median imputation and standardization inside each training partition. The stack uses logistic regression, random forest and SVM base learners, each with its own preprocessing inside the inner five-fold cross-validation. Hyperparameters are fixed in code. The majority-class baseline is fit on each training partition. Positive F1 refers to class 1. Macro F1 gives the two classes equal weight. Baseline-visit metrics pool all out-of-fold predictions. The aggregate CSV includes all four confusion-matrix counts for every run. [Analysis](analyze.py) · [Results](results/reanalysis.csv)

**Interpretation.** The original OASIS study used clinical assessments, including CDR, to characterize dementia. The two evaluation protocols have different targets, units and validation designs. Comparisons of feature sets within one protocol hold the tested observations fixed. The MRI-only inputs are two global measurements. The results do not measure the performance of a system using the full scans. The cohort and sample size limit generalization to other settings.
